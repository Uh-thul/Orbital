# ORBITAL: Crew Health Console

Team ESP32 | NASA Space Apps Challenge 2026
Aabael RL, Ananthakrishnan K, Athul PK, Vaishnavu S

ORBITAL is a self-check health console for astronauts on long-duration missions, where ground medical help is delayed. Crew members enter their own readings and see a color-coded readiness score, trend charts, a clickable body map and plain-language guidance on when to contact a flight surgeon.

Live project: https://uh-thul.github.io/Orbital/
Demo deck: https://uh-thul.github.io/Orbital/ORBITAL-demo-deck.pdf

Notes
- All readings are entered by the user; no medical hardware is connected.
- Sample data is labeled and is not measured data.
- Built with AI assistance (Claude) for code and design.
